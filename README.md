# Pipeline '27

A single-page tracker for sophomore IB and consulting recruiting. It covers fall 2026 insight programs and events through the 2027 recruiting season (summer 2028 internships), across the US, the Middle East/GCC and UK/EMEA.

## What's in it

- **Agenda**: every opening, deadline and event by month, with a "next three weeks" list at the top.
- **Programs**: all ~85 programs in one list. You can search it and filter by type and status.
- **Firms**: the 43 firms on the target list, grouped by tier, each with its next date and a careers link.
- **Playbook**: what to do in each phase, from now through the Middle East summer-2028 wave in fall 2027.
- **Status and notes** on every item, plus your own events (info sessions, coffee chats).

## Date confidence

Each item is tagged:

- **Confirmed**: the 2026–27 date was published by the firm or a university career office.
- **Est. from last cycle**: projected from last year's window. Check the firm's site as the date gets close.
- **Rolling**: no fixed close, so apply early.
- **Watch**: the program was paused or cancelled last cycle.

## Running it

- `tracker.html` is the page body used for the published Claude artifact. There, progress saves to your account.
- `index.html` is a standalone copy generated by `./build.sh`. Open it in a browser or serve it with GitHub Pages. In this copy, progress saves to the browser's localStorage.

To add or change programs, edit the `add({...})` entries in `tracker.html`, then run `./build.sh`.
